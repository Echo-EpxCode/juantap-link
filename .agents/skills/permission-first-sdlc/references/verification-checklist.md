# Verification checklist

- [ ] The check is connected to expected behavior and changed files.
- [ ] Its side effects are understood (writes, installs, network, database, external state).
- [ ] It was requested or authorized before execution.
- [ ] Exact command/check, observed result, and exit code are recorded where available.
- [ ] Result is labeled passed, failed, blocked, or not run.
- [ ] No browser, integration, database, or deployment check is claimed without evidence.
- [ ] Generated files, limitations, and remaining risks are reported.
